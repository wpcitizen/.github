# Support

For help with a WP Citizen project, start with the README and documentation in that project's own repository. Check the supported versions, installation instructions, FAQs, and existing issues before opening a new request.

## Where to ask

- **Bug reports:** use the bug report form in the affected repository.
- **Feature ideas:** use the feature request form or the project's Discussions area, if enabled.
- **Usage questions:** use Discussions when the project enables it; otherwise follow the support route documented by that project.
- **Security concerns:** never use a public issue. Follow [SECURITY.md](SECURITY.md).

Please include relevant version and environment details, but remove passwords, API keys, payment information, private customer data, and other secrets from logs or screenshots.

Some repositories may be experimental, archived, or community-maintained. Check each repository's status and support notes before relying on it in production.
