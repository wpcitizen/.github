# WP Citizen — organization defaults

This repository is the organization-wide home for WP Citizen's public GitHub profile and default community-health files. A repository's own files take precedence over these defaults.

## What lives here

- [`profile/README.md`](profile/README.md) — the public organization profile shown at [github.com/wpcitizen](https://github.com/wpcitizen).
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — shared contribution expectations.
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) — community behavior standards.
- [`SECURITY.md`](SECURITY.md) — responsible vulnerability reporting guidance.
- [`SUPPORT.md`](SUPPORT.md) — where to ask for help and how to report problems.
- [`ACCESSIBILITY.md`](ACCESSIBILITY.md) — accessibility expectations for products and documentation.
- [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) — reusable issue forms for repositories that do not define their own.
- [`BRAND.md`](BRAND.md) — logo assets, palette, and basic usage guidance.
